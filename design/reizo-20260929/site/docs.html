快速开始

  1. 创建项目凭证

    在API 密钥中按项目规划权限与有效期。真实密钥创建待账户服务接入。

  2. 确认模型与网关

    在模型目录确认 Model ID、可用状态和计费单位。网关尚待统一，本页仅使用环境变量占位，不指向旧系统。

  3. 从服务端发送测试请求

    先用小规模输入检查返回内容、用量与错误，再接入正式业务。此文档不执行真实请求。

文档迁移稿：以下为接口格式指引，不代表所有模型已通过接入验证。正式网关、支持参数、响应结构与限流值需由后端确认后补齐。

鉴权与密钥

把密钥放在服务端环境变量 REIZO_API_KEY 中；通过 Authorization: Bearer … 传入。不要放进网页源码、截图或支持工单。

REIZO_API_BASE 表示平台确认的网关根地址，不含 /v1。在服务未接入前，不要向任何示例地址发送真实密钥。

文本与推理

兼容格式模板：POST /v1/chat/completions。基础请求包含 model 与 messages；模型是否支持流式输出、工具调用和其他参数，需以正式接口能力为准。

# 先配置已确认的服务端环境变量
curl --fail-with-body "${REIZO_API_BASE}/v1/chat/completions" \\
  -H "Authorization: Bearer $REIZO_API_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{"model":"YOUR_MODEL_ID","messages":[{"role":"user","content":"你好"}]}'

图像生成

通用格式模板为 POST /v1/images/generations，通常包含模型与提示词。分辨率、尺寸、图片数量及返回格式并非各模型通用，不要把一种模型的参数直接复制给另一种。

价格可能随尺寸、质量或计费分组变化。请先核对目录中的单位和状态。

模型专用协议

部分模型使用专用图像或多模态协议，不直接套用通用 Images 路径。专用路径、消息结构、文件限制及返回解析方式待正式接口确认后补齐。

专用协议未确认前，不提供猜测出的可执行请求。

视频任务

视频通常采用“提交任务 → 获取任务 ID → 查询状态 → 取得结果”的异步流程。现有模板使用 /v1/video/generations，但仍需确认目标模型的适用路径与参数。

  1. 提交提示词和经确认支持的参数。
  2. 保存任务 ID；排队或处理中不代表已生成成功。
  3. 按服务端约定查询状态；仅在成功状态读取结果。
  4. 失败时保留请求 ID，到调用日志排查，避免盲目重复提交。

额度与计费

工作台和 API 共用会员月度额度与另购余额；每日体验额度仅限工作台。会员月度额度当期有效，另购余额长期有效。

购买额度本身不因会员折扣而囤入更多余额；优惠按消费当时的有效会员规则扣减。准确规则见定价页。
