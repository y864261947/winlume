一、打开预览
先完整解压，不要在压缩包里直接打开文件。

推荐：电脑安装 Python 3 后，在此文件夹打开终端运行：
Windows：py start-preview.py
macOS / Linux：python3 start-preview.py
浏览器会自动打开；若没有自动打开，复制终端显示的地址。
保持终端窗口开启；结束预览时按 Ctrl+C。
服务仅监听自己的电脑，自动选择空闲端口，不会公开到互联网。

若暂时没有 Python，可双击 site/index.html 查看主要页面；
完整交互与本地存储建议使用上述 HTTP 预览方式。
也可以用 VS Code 的 Live Server 打开 site/index.html。

二、继续开发
site 文件夹就是完整的静态网站源代码，可直接编辑 HTML、CSS、JavaScript。
不需要 npm 安装或构建。静态托管时，将 site 的内容作为网站根目录。
首页 index.html；工作台 studio.html；工作台介绍 agent.html；
API 接口 api.html；会员价格 pricing.html；账户 account.html；企业服务 business.html。
部署时请自行配置所需访问权限，不要把评审版本误当成生产服务。
