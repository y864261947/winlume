接入前，你可能想知道。

工作台会员和 API 计费是一回事吗？

工作台与 API 共用会员月度额度和另购余额，无需会员也可按量使用。API 先扣当期会员包含额度；用完后从另购余额扣减，会员有效期内享对应的额外用量折扣。会员到期后，另购余额仍长期有效，但后续用量恢复标准扣减。每日登录赠送的 100 点体验额度仅限工作台使用，不能用于 API。工作台同时执行任务的数量也不等于 API 并发限额；会员不代表 API 免费或不限量。查看会员与价格 ↗

为什么标注“参考价”和“价格待核对”？

这里整理了现有模型目录的价格快照，并保留“起价”和调用分组条件。部分视频条目的原始计费单位与能力分类不一致，因此单独标注，不作为确定报价。最新价格以实时目录及控制台为准。

可以直接沿用已有的调用代码吗？

现有文档提供 OpenAI 兼容格式等接口，但不同模型、图像和视频能力不一定使用同一个路径或参数。请先核对具体接口；本页示例是格式模板，不代表全部模型已经通过调用验证。查看 API 参考 ↗

调用失败、限流或扣费有疑问怎么办？

先在调用日志中记录请求时间、模型、请求 ID 与错误码，再联系支持。请勿提交 API 密钥。失败是否计费、限流额度与重试策略需按具体接口及账户规则确认。联系使用支持 ↗
