工作台与 API 有什么区别？＋

工作台通过对话组织任务与成果，适合直接创作和处理工作。API 面向开发者，将模型能力接入自己的应用。两种方式使用同一套账户额度。

我需要先选好模型吗？＋

可以从 REIZO 自动模式开始，也可以在工作台中手动选择模型。首页展示的是交互示例，实际可用能力以工作台与模型目录为准。
