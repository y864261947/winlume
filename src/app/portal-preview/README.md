# 新版门户预览

本地地址：`/portal-preview`。旧首页 `src/app/page.tsx` 保持原样。

页面由 `src/components/portal-preview/PortalPreview.tsx` 和独立 CSS Module 组成，包含工作台输入、功能轮播、模型滚动展示、行业助手、企业服务和现有 `PortalFooter`。

- 输入内容通过工作台已有的 `prompt` 参数带入草稿；Enter 进入工作台，Shift+Enter 换行，中文输入法确认候选词不会提交。
- 行业助手从启用的 Skills 中选取，使用现有 `applicationCatalogSkillHref` 带入 Skill、名称和可用的示例任务。策划列表位于 `src/lib/portal/preview-roles.ts`。
- 配置了数据库时，模型卡片读取 `getPublicPortalContent()` 的已发布目录。本地未配置数据库时才使用 `model-snapshot.json`，并在页面显示快照日期。
- 快照来自 `https://reizo-ai.com/api/portal/content`，采集日期为 2026-09-23；仅保留公开模型目录，图片映射到现有本地供应商图标。它用于本地预览，不作为正式首页的回退目录。
- 监控轮播是标有「演示数据」的功能介绍，入口进入真实用量页面，不代表实时平台监控。
- 会员、登录、搜索复用原有弹窗。未增加收费、运行任务或部署动作。
- 功能轮播每 6 秒切换；悬停、键盘焦点、页面隐藏和系统减少动态效果设置会暂停。模型横向滚动支持暂停、手动浏览和减少动态效果设置。

确认后替换首页时，可在首页服务端加载已发布模型目录和启用的 Skills，传入该页面组件；不要把预览模型快照一并接入正式首页。预览路由禁止搜索引擎索引。
