# 首屏之后的内容设计

参考页面于 2026-10-06 实际打开、滚动并操作：

- [Cursor](https://cursor.com/)
- [Grok Bot](https://x.ai/bot)

Cursor 的主要功能段落采用左右交替的版式，产品演示占约三分之二的
空间。说明文字靠近演示，标题约 22px、常规字重；模型、更新和资源等
辅助内容在主产品叙事之后收成较小的模块。

Grok Bot 在大段产品介绍后使用两列能力展示，再通过原位切换的任务按钮
展示具体场景。案例选择会同时更新说明与右侧画面。后面依次安排价格、
下载、指南、FAQ 和页脚，信息分层清楚。

## 在 REIZO 中的对应实现

保留白色页面、夜间产品界面以及原项目的左侧栏。首屏之后依次为：

1. 创作画布：短说明配大幅、可操作的实际画布。
2. 项目与作品：画面与文字交换位置。短片、套图、内容计划在原位切换；
   查看项目会切换已有的首屏样例，不打开弹窗或全屏。
3. 模型与 API：大幅代码示例；模型品牌放在 API 说明中，不作为客户背书。
4. 电脑与网页：保留真实入口，去掉模拟手机拼贴与未经代码证明的接续画面。
5. 会员与 API 计费、FAQ、页脚：短说明和真实站内链接。

展示资产来自现有项目。短片为已有的 12 秒 MP4；套图为已有输出；内容
计划的 Markdown 和 JSON 从桌面样例的 `research-calendar` 节点导出。
没有使用参考站的图像、字体、案例或客户评价。

`ProjectShowcase.tsx` 使用 shadcn Tabs 的 line 变体。短片只提供播放/暂停，
没有原生全屏控件；切换类型会停止播放。计划可以下载原始 Markdown。
`landing.css` 统一了字号、空间和响应式规则，首屏动效仍由
`LandingIntro.tsx` 控制，原站时序与缓动没有改动。

## 验证

- 页面相关 ESLint、目标 TypeScript 检查和 CSS 解析。
- 浏览器检查三种作品切换、套图选择、键盘右箭头切换、项目定位。
- 短片实际播放：readyState 4、duration 12、paused false；切换后停止。
- 复制完成后确认剪贴板含示例 API Key；FAQ 展开正常。
- 手机单列排版、文档表格、导航关闭和 API 区；390px 视口没有页面横向溢出。
- 减少动态效果模式：标题字词与各层直接显示；首屏仍为 60px / 63px。
- 页内导航采用原生锚点，重复点击同一项也能重新定位。
- 刷新保留纯项目占位图；原侧栏和首页轻体验约束保留。
